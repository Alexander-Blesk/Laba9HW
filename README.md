# Алгоритм и блок-схема

- Начало
- Настройка русской локализации (setlocale)
- Запуск внешнего и внутреннего циклов for для построчного сканирования экрана и вывода графического изображения фигуры с помощью символов *, +, |, -   
- Переход к интерактивной части программы с использованием цикла while
- Получение координат точки $x$ и $y$ от пользователя
- Вызов функции check(x, y) для проверки попадания точки по формуле: x <= 0 && y <= 0 && y >= -x - 4.5 && (x * x + y * y) >= 3.0
- Если условие верно, вывести сообщение: "Точка принадлежит графику"
- Если условие неверно, вывести сообщение: "Точка не принадлежит графику"
- Запрос на продолжение работы (если введено 0, цикл завершается)
- Конец
